# GestUniv Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in GestUniv:
1. Please do not open a public issue.
2. Contact the development team or submit a private security advisory through GitHub Security Advisories.
3. Include detailed steps to reproduce the vulnerability.

Security updates are prioritized and released as quickly as possible.
